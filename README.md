# Wolf Wheels

Personal, unofficial Hot Wheels gallery for Android.
Data and photos come live from the [Hot Wheels Wiki (Fandom)](https://hotwheels.fandom.com) public API, no key needed.

## Features
- Model search and collections (2026, 2025, 2024, Treasure Hunts, Super Treasure Hunts, Monster Trucks)
- Model page: spec sheet, history, card facts, notes and every photo
- Versions: pick any released version to see its photo and data (year, series, colour, tampo, base, interior, wheels, toy number, country, notes); filter by type and sort
- Full-screen photo viewer: swipe, pinch or double-tap to zoom
- In-app updates (downloads the APK from Releases and checks its SHA-256)

## Builds
Every push to `main` builds the APK with GitHub Actions and publishes a release `v1.0.<run>` with `WolfWheels.apk` and `WolfWheels.apk.sha256`.
Latest APK: https://github.com/jonatanmonteror-gif/noir-wheels/releases/latest/download/WolfWheels.apk
